# 01_团队治理与协作

## 核心原则

所有设计、任务和协作都应服务于实际问题。不能只追求形式上的完成，而要确保任务最终可以交付、调试、维护、拍摄和比赛使用。

## 队伍组织架构

本队当前采用轻量化管理架构，核心岗位为队长、经理、四位组长、七位兵种组长。

```text
队长
├─ 经理
├─ 四位组长
└─ 七位兵种组长
```

其中，队长负责队伍总目标、技术路线、项目优先级和关键取舍；经理负责运营、财务、采购协同、报销、宣传、外联和后勤；四位组长负责各自方向的人员、培训、方案把关、任务拆解和验收；七位兵种组长负责对应兵种或系统从设计、制造、联调、测试、视频拍摄到比赛使用的完整交付。

这套架构的核心不是增加职位，而是明确三类责任：

- 队长对赛季结果和关键决策负责。
- 组长对方向能力建设和本组交付质量负责。
- 兵种组长对具体机器人或系统能否稳定交付负责。

## 队长职责

- 制定赛季整体目标和时间节点。
- 协调跨组资源和冲突。
- 发现重大延期后及时重新分配任务。
- 确保报名、规则、材料、视频等关键事项按期完成。
- 推动赛季复盘和传承文档完成。
- 组织关键技术路线、关键采购和任务取舍评审。
- 在进度失控时决定保留、降级或舍弃哪些任务。

## 经理职责

- 负责队伍运营、财务、采购协同、报销、宣传、外联、后勤和文化建设。
- 维护经费使用、报销状态、待报销事项和物资流转记录。
- 协助队长完成招新、团建、赛事材料、差旅和后勤保障。
- 参与关键采购流程，但不在未组织技术评审的情况下单方面否决关键技术物资。
- 定期向队长和核心管理层同步预算、报销和物资状态。

## 组长职责

- 拆解本组任务。
- 明确负责人、协作人、截止时间和验收标准。
- 检查组员设计或实现的合理性、必要性和风险。
- 发现阻塞后及时协调。
- 维护本组文档和资料归档。
- 负责本组新人培训、成员培养和方向能力建设。
- 对本组任务结果进行验收，而不只是分配任务。

## 兵种组长职责

- 对该兵种从设计、装配、调试到视频拍摄负责。
- 组织机械、电控、算法联合评审。
- 在联调和考核视频拍摄时保证相关负责人到场。
- 记录该兵种问题、改进建议和下一届注意事项。
- 对该兵种是否能稳定比赛、是否完成材料提交、是否完成赛后复盘负责。
- 当兵种任务被某一技术方向阻塞时，及时同步对应组长和队长。

## 跨组协作原则

1. 新车设计前必须进行机械、电控、算法联合沟通。
2. 机械方案需要提前考虑走线、主控、分电板、电机选型、电机朝向和维修空间。
3. 电控和算法需求不能等机械全部完成后才提出。
4. 自瞄、导航等系统第一次调试时，兵种机械、电控、算法负责人应同时在场。
5. 任何设计都应说明它给其他组带来的额外难度。

## 任务死锁处理机制

当任务出现“我在等他，他在等我”的情况时，必须立即处理。

| 阻塞时间 | 处理方式 |
| --- | --- |
| 当天 | 负责人在任务群或飞书任务中说明阻塞原因 |
| 超过 24 小时 | 组长介入，明确下一步动作 |
| 超过 48 小时 | 队长介入，必要时重新分配任务 |

## 消极、失联和延期处理

根据队伍实际情况制定提醒、约谈、替换负责人、取消资格等处理方式。

## 上一届答疑机制

- 暑假前优先线下答疑。
- 离校后保留线上联系方式。
- 每个关键方向至少指定一名上一届答疑人。
- 答疑内容应整理回文档，不只停留在聊天记录。
